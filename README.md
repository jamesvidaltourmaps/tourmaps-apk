# TourMaps GO+ — candidatas Android

Descargas de prueba de TourMaps GO+ firmadas con la clave original de la app.

Cada entrega incluye APK, versión, hash SHA256, fuente revisada y límites de comprobación. Son candidatas para pruebas; no representan una publicación en Google Play.

La firma original es diferente de la usada por las candidatas del canal `Ahgarzon/tm-apk`. La compatibilidad de una actualización depende de la firma de la app instalada. No es necesario desinstalar ni borrar datos para comprobarlo.

Este repositorio contiene información de distribución y archivos adjuntos en Releases. El código fuente, configuraciones privadas y archivos de firma se mantienen fuera de este repositorio.
